# 🐾 PETS-HELP

Uma nova chance para eles. Um novo propósito para nós.

## 📌 Sobre o projeto

A PETS-HELP é uma ONG fictícia desenvolvida para fins acadêmicos e educacionais.

O projeto tem como objetivo apresentar uma plataforma web voltada à proteção, cuidado e adoção responsável de animais em situação de rua, além de incentivar a participação da comunidade.

A proposta também busca criar um espaço de convivência entre pessoas e animais, promovendo conexão, pertencimento e um senso de propósito por meio da participação na comunidade.

## 🖥️ Estrutura do projeto

O site é dividido em três páginas principais:

- `index.html` — Página inicial, apresentação da ONG e animais disponíveis para adoção.
- `projetos.html` — Projetos da ONG e formas de participação.
- `cadastro.html` — Formulário para cadastro e demonstração de interesse.

### Outros arquivos

- `style.css` — Estilos visuais e responsividade do site.
- `imagens/` — Imagens utilizadas na seção de adoção.

## 🐶 Adoção

A página inicial apresenta animais fictícios disponíveis para adoção:

- Ani
- Luna
- Vader

Cada animal possui uma descrição, imagem e acesso ao formulário de cadastro.

## 🤝 Projetos

Entre as iniciativas apresentadas estão:

- Resgate e Acolhimento
- Assistência Veterinária
- Jornadas de Castração
- Apoio e Voluntariado
- Doações
- Apoio como estudante
- Cuide de Quem Cuida

## 📝 Formulário

O cadastro utiliza recursos nativos do HTML5 para validação dos dados, incluindo:

- Campos obrigatórios
- Validação de e-mail
- Idade mínima
- Formato de CPF
- Formato de telefone
- Formato de CEP

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Visual Studio Code

## 📚 Finalidade

Projeto acadêmico fictício desenvolvido para fins educacionais, com foco no aprendizado de desenvolvimento web, estrutura semântica HTML5, formulários, acessibilidade e design responsivo.
